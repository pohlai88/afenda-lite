## Package README

Canonical, framework-neutral Fetch transport mechanics for correlation, pagination, middleware, and safe response headers.

## Consume

Use the single package-root capability:

```ts
import { http } from "@afenda/http";

const context = http.correlation.createContext(request);
const page = http.pagination.extract(request);
const headers = new Headers();

http.headers.applyRetryAfter(headers, 30);
http.headers.applyRateLimit(headers, {
	limit: 20,
	remaining: 17,
	resetEpochMs: Date.now() + 60_000,
});

export const GET = http.pipeline.withContext(async (_request, ctx) =>
	new Response(JSON.stringify(page), {
		headers: { [http.correlation.header]: ctx.correlationId },
	}),
);
```

The stable capability groups are `correlation`, `pagination`, `headers`, `pipeline`, and `response`. Only types are additionally exported from the root. There are no public subpaths.
